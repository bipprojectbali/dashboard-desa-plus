- SyncLog terbaru muncul di tabel riwayat sinkronisasi
- Trigger NOC sync gagal → alert error muncul
- Halaman menampilkan waktu sync terakhir
- Non-admin tidak dapat mengakses halaman sinkronisasi

### 5. `.github/workflows/e2e.yml` (baru)
GitHub Actions workflow E2E:
- Trigger: push/PR ke `stg` atau `main`
- Job `build`: install deps, generate Prisma, build frontend, upload artifact
- Job `e2e` (depends on `build`): setup PostgreSQL service, migrate DB, seed auth, install Playwright Chromium, run test suite
- Upload `playwright-report` sebagai artifact (7 hari)

## Catatan Teknis
- Semua test menggunakan `page.route()` untuk mock API — tidak butuh database aktif saat testing
- Pattern mock session: `{ data: { user: { role: "admin" } } }` untuk simulasi login
- Playwright config di `playwright.config.ts`: testDir `__tests__/e2e/`, browser Chromium, webServer via `bun src/index.ts`
- File test menggunakan `test.beforeEach` untuk reuse mock session setup
